# CSDemoCRM2（顧客・ケース管理のデモ）

音声認識システムとの連携を想定した、コールセンター向け CRM のデモアプリです。顧客ごとのケース（1件の問い合わせ・対応）を GUI で管理し、コマンドラインからは**検索結果の CSV 出力**と**ケースの自動起票**ができます。

- 配布物は **`dist\CSDemoCRM2.exe` の1ファイルだけ**（約130KB）。インストール不要、DLL不要。
- Windows 10 / 11 に標準で入っている .NET Framework 4.8 で動くため、配布先に追加インストールは不要です。
- **顧客**は固定項目（顧客名・会社名・電話番号・メール・住所・備考）、**ケース**は自由に定義できるフィールドです。
- データは exe と同じフォルダの `crm_data.xml` に自動保存されます（書き込めない場所では `%LOCALAPPDATA%\CSDemoCRM2\`）。

```
音声認識システム ──(通話中・通話後にコマンド実行)──> CSDemoCRM2.exe --add --set ...
                                                        │
                                                  顧客を特定（無ければ作成）してケースを起票
                                                  開いている画面へ自動反映
```

## 画面

| 画面 | できること |
|---|---|
| 顧客一覧（左） | 顧客の登録・編集・削除。顧客名・会社名・電話番号・メール・ケースの内容で絞り込み |
| ケース一覧（右） | 選択した顧客のケースを一覧表示。**表示する列は自由に選択**（`Ctrl+L`） |
| ケースの編集 | 一覧を**ダブルクリックすると全フィールドの表示・編集画面**が開く。型に応じた入力欄（日付・選択リスト・チェック・URL など） |
| フィールド設定 | ［データ］→［フィールド設定］（`F4`）。項目の追加・編集・削除・並べ替え。ここで追加すると、画面の入力欄とコマンドの変数名が同時に増える |
| 連携検索テスト | 音声テキストから取り出した値で検索を試し、標準出力とコマンドを確認（`Ctrl+Shift+P`） |
| 連携CSV出力プレビュー | 選択中の顧客で exe を実行したときの標準出力を確認・コピー（`Ctrl+P`） |
| インポート / エクスポート | CSV・タブ区切りテキストの取り込み（プレビュー付き）、顧客一覧・ケースの CSV 出力 |
| 表示 | ライト／ダーク／Windows の設定に合わせる（`Ctrl+Shift+L`、ステータスバーのクリックでも切替。設定は保存されます） |
| データ管理 | サンプルデータ投入、バックアップ、データフォルダを開く、顧客とケースの全削除 |

主なショートカット: `Ctrl+N` 新規顧客 / `Ctrl+T` ケースを追加 / `Ctrl+F` 検索 / `Ctrl+L` 表示する列 / `F4` フィールド設定 / `Ctrl+I` インポート / `Ctrl+E` 全ケースのエクスポート / `F5` 再読み込み / `F1` コマンドラインの使い方

コマンドラインでケースが起票・更新されると、**開いている画面に約1.5秒で反映**され、その顧客とケースが自動で選択されます。

## フィールド定義（ケースの項目）

初期状態では次の9項目が定義済みです。`F4` の画面で増やせます。

| 表示名 | 変数名 | 型 | 一覧・標準出力 | キー項目 |
|---|---|---|---|---|
| 通話ID | `call_id` | テキスト | | ○ |
| 件名 | `subject` | テキスト | | |
| 通話日時 | `call_date` | 日時 | | |
| オペレータ | `operator_name` | テキスト | | |
| 用件区分 | `category` | 選択リスト | | |
| 通話詳細URL | `detail_url` | URL（リンク） | | |
| 問い合わせ内容 | `summary` | 長文テキスト | ○ | |
| 対応内容 | `response` | 長文テキスト | ○ | |
| 次回確認内容 | `next_action` | 長文テキスト | ○ | |

- **型**: テキスト / 長文テキスト / URL（リンク）/ 数値 / 日付 / 日時 / 選択リスト / チェックボックス
- **一覧・標準出力**: ケース一覧の初期表示と、検索の標準出力に含める項目
- **キー項目**: 1つだけ指定できます。同じ値のケースがあれば更新、無ければ新規起票（通話中に複数回送っても1件にまとまります）

## コマンドライン（他システム連携）

### 検索

```bash
CSDemoCRM2.exe "山田 太郎"
```

```csv
問い合わせ内容,対応内容,次回確認内容
新システムの導入を検討中。製品資料を送ってほしい。,製品資料と価格表をメールで送付。,資料の確認状況をヒアリング
```

日付や件名も渡したい場合は、フィールド設定で「一覧・標準出力に含める」に `通話日時` や `件名` を追加してください。

- 出力される列は「一覧・標準出力に含める」にした項目です（並び順もフィールド設定の順）。
- 並びは日付項目の古い順。1行目は見出し（表示名）。カンマ・改行・`"` を含む項目は RFC 4180 形式で囲みます。
- `--full` を付けると `顧客ID,顧客名,会社名,電話番号,メール,ケース番号` と全フィールドを出力します。

#### 検索条件（顧客の特定。検索・起票で共通）

| オプション | 対象 | 照合ルール |
|---|---|---|
| `-n, --name <値>` | 顧客名 | 完全一致（`--partial` で部分一致） |
| `-c, --company <値>` | 会社名 | 部分一致。`株式会社`・`(株)` などの法人格は無視 |
| `-t, --phone <値>` | 電話番号 | 数字だけで比較。10桁以上は全桁一致、4〜9桁は末尾一致 |
| `-a, --any <値>` | 上の3項目のどれか | どれか1つに一致すれば該当 |
| `--id <顧客ID>` | 顧客ID | 完全一致 |

- 同じ項目内の複数値は **OR**（`--name "山田太郎,佐藤花子"`、`,` `、` 区切り）、異なる項目どうしは **AND**。
- 空白・全角半角・大文字小文字、末尾の「様」「さん」は区別しません。
- 複数の顧客に該当しうる検索では `--full` を付けると、行ごとに顧客名・会社名が入ります。
- `--pick` を付けると、2件以上該当したときだけ選択画面が出ます（`--pick-timeout <秒>` で自動キャンセル）。

### ケースの起票（`--add`）

```bash
CSDemoCRM2.exe --add --name "山田 太郎" --phone 03-1234-5678 --set call_id=C12345 --set subject="導入時期の相談" --set summary="来月初旬の導入で合意したい" --set response="スケジュール案を送付" --set next_action="キックオフ日程の確定"
```

```text
起票しました（顧客ID:1 山田 太郎（株式会社サンプル商事）、ケース番号:CS-00019）
```

- **顧客の特定**: 検索条件で1件に決まればそこにケースを追加します。
- **顧客がいない場合**: `--name` / `--company` / `--phone` の値で**新しい顧客を作り**、そこにケースを起票します（`--no-create` で抑止すると終了コード `1`）。
- **`--any` だけで起票する場合**: 顧客が見つからなければ、値を**「顧客名,会社名,電話番号」の順**とみなして新しい顧客を作ります（デモ用の割り切り）。
  - 空欄はそのまま「なし」として扱います（`--any "小林 恵,,080-9999-0000"` は会社名なし）。
  - `--name` / `--company` / `--phone` を一緒に指定した場合は、そちらを優先します。
  - 1つ目（顧客名）が空のときは作成せず、`該当する情報がありません`（終了コード `1`）を返します。
  - どう振り分けたかはログに残ります（例: `--any から新規顧客を作成（顧客名=小林 恵、会社名=なし、電話番号=080-9999-0000）`）。

```bash
CSDemoCRM2.exe --add --any "森田 拓也,株式会社モリタ物流,045-222-3333" --set call_id=C-5001 --set summary="配送状況を知りたい"
```
- **顧客が複数該当**: 起票せず候補を出力して終了コード `2`（`--pick` で選択画面）。
- **キー項目による集約**: `call_id` などキー項目に同じ値のケースがあれば、そのケースを更新します（`--new` で常に新規）。
- `--case CS-00001` でケース番号を直接指定して更新できます。
- 必須の日付項目が指定されていないときは、起票時に今日の日付が入ります。
- 値の中の `\n` は改行、`%VAR%` は環境変数の値に展開します。
- 定義されていない変数名は無視し、警告を標準エラー出力に出します（コマンドは失敗しません）。

| オプション | 内容 |
|---|---|
| `--set <変数名>=<値>` | ケースの値（複数指定可。`--set` を省略して `変数名=値` でも可） |
| `--new` | キー項目が一致しても必ず新しいケースを作る |
| `--case CS-00001` | ケース番号を指定して更新 |
| `--no-create` | 顧客が見つからないとき新規作成しない |
| `--email <メール>` | 顧客を新規作成するときのメールアドレス |
| `--fields` | 定義済みのフィールド一覧をCSVで出力（変数名の確認用） |
| `--sample` | デモ用のサンプルデータを投入（顧客8件・ケース18件） |

### 環境変数からの取り込み

音声認識システムが環境変数で値を渡す場合に使います。

```bash
CSDemoCRM2.exe --add --name "%CUSTOMER%" --phone "%ANI%" --env-prefix AMIVOICE_CS_
```

| オプション | 内容 |
|---|---|
| `--env-prefix [接頭辞]` | 接頭辞に一致する環境変数を、同じ名前のフィールドへ入れる（省略時 `AMIVOICE_CS_`）。`AMIVOICE_CS_SUMMARY` → `summary` |
| `--set-env <変数名>=<環境変数名>` | フィールドと環境変数を明示的に対応させる |
| `--show-env [接頭辞]` | 渡された環境変数と、対応するフィールドを一覧表示 |

優先順位は `--env-prefix` → `--set-env` → `--set` の順で、あとに指定したものが優先されます。対応するフィールドが無い環境変数は無視し、警告を出します。

### 通話の途中経過を送る

同じ `call_id` を付けて複数回実行すると、1件のケースにまとまります。

```bash
CSDemoCRM2.exe --add --phone "%ANI%" --name "%CUSTOMER%" --set call_id=%CALLID% --set status=未完了
```
```bash
CSDemoCRM2.exe --add --set call_id=%CALLID% --set summary="%SUMMARY%"
```
```bash
CSDemoCRM2.exe --add --set call_id=%CALLID% --set response="%RESULT%" --set next_action="%NEXT%"
```

2回目以降はキー項目でケースが特定できるため、顧客の条件を省略できます。

### 標準入出力と終了コード（連携時の判定）

結果は**標準出力**、エラーと警告は**標準エラー出力**に分けて出します。

**結果が得られなかったときの標準出力は、理由にかかわらず `該当する情報がありません` の1行に統一**しています（該当なし・条件の値が空・選択のキャンセル）。理由の違いは終了コードとログで判別してください。

| 状況 | 標準出力 | 終了コード |
|---|---|---|
| 検索：該当あり | ケースのCSV（1行目は見出し） | `0` |
| 検索：該当なし／条件の値が空 | `該当する情報がありません` | `1` |
| 起票・更新：成功 | `起票しました（…ケース番号:CS-00019）` | `0` |
| 起票：顧客が見つからない（`--no-create`） | `該当する情報がありません` | `1` |
| 顧客が複数該当（起票時） | 候補の `顧客ID,顧客名,会社名,電話番号` のCSV | `2` |
| `--pick` でキャンセル | `該当する情報がありません` | `2` |
| エラー（オプションの誤りなど） | なし（標準エラー出力に `エラー: …`） | `9` |

- 条件のオプションを指定して値が空だった場合（`--any ","` など）はエラーにせず、該当なしとして扱います。条件のオプション自体が無い場合は終了コード `9` です。
- 連携側では文字列ではなく**終了コード**で判定してください。
- **0 以外をすべてエラーとみなす連携先**（「コマンドがエラー終了しました」と表示されるなど）では、`--exit0` を付けてください。該当なし（1）・複数該当や選択のキャンセル（2）も終了コード `0` で返します。標準出力の内容は変わらないので、`該当する情報がありません` で結果の有無を判定できます。オプションの誤りなどの本当のエラーは `9` のままです。

### 文字コード

パイプ・リダイレクト時の既定は、標準出力・標準エラー出力ともに **BOMなしUTF-8** です。

| 指定 | 標準出力 | 標準エラー出力 |
|---|---|---|
| なし（既定） | BOMなしUTF-8 | BOMなしUTF-8 |
| `-e utf8bom` | BOM付きUTF-8（Excelでそのまま開ける） | BOMなしUTF-8 |
| `-e sjis` | Shift_JIS | Shift_JIS |

```python
import subprocess
r = subprocess.run([r"C:\path\to\CSDemoCRM2.exe", "山田太郎", "--full"],
                   capture_output=True, encoding="utf-8")
if r.returncode == 0:
    cases_csv = r.stdout
elif r.returncode == 1:
    cases_csv = None            # ケースなし
else:
    raise RuntimeError(r.stderr)
```

```powershell
# Windows PowerShell 5.1 で変数に受けるときは sjis を指定（PowerShell 7 以降は不要）
$csv = & .\CSDemoCRM2.exe 山田太郎 -e sjis
```

## インポート形式

1行目が見出しなら、**顧客の項目**（顧客名, 会社名, 電話番号, メール, 住所, 備考）と、**フィールド設定の表示名・変数名**で自動判別します（順不同、不要な列は無視）。

**顧客の特定**

- `顧客ID` 列があれば、その顧客に取り込みます（顧客名より優先）。存在しないIDはエラー行として飛ばします。
- 無ければ「顧客名＋会社名」で特定し、見つからなければ**新しい顧客を作ります**。既存顧客は空欄の項目だけ補完します（入力済みの値は上書きしません）。
- 見出しがない場合は「顧客名,会社名,電話番号,メール」＋一覧に表示している項目の順とみなします。
- 先頭列が日付で見出しがない場合（このアプリの標準出力と同じ形）は、GUI で選択中の顧客に取り込めます。

**ケースの追加・更新**

- `ケース番号` 列があれば、その**既存ケースを更新**します。
- 無くても、キー項目（`call_id`）が同じ顧客のケースにあれば、そのケースを更新します。
- どちらも無ければ新しいケースを作ります。指定した項目の値がすべて同じケースがある場合は重複としてスキップするので、同じファイルを何度取り込んでも安全です。
- `顧客名` のように顧客とケースの両方にある見出しが2つ並んでいる場合、1つ目は顧客、2つ目はケースのフィールドとして扱います（エクスポートしたCSVをそのまま戻せます）。
- 文字コードは UTF-8（BOM有無）／Shift_JIS／UTF-16 を自動判別します。

**サンプルデータの作り方（エクスポート → 編集 → インポート）**

```bash
CSDemoCRM2.exe --all > cases.csv
```

Excel などで内容を書き換えたり行を足したりしてから、戻します。

```bash
CSDemoCRM2.exe --import cases.csv
```

- ケース番号がある行は更新、空にした行や新しい行は追加されます。
- 顧客名・会社名・電話番号を書いた行は、その顧客がいなければ新しく作られます。
- GUI では［ファイル］→［インポート］に貼り付けると、取り込み前に行ごとの判定（新規・更新・重複・エラー）を確認できます。

## データファイル

| ファイル | 内容 |
|---|---|
| `crm_data.xml` | 顧客・ケース・フィールド定義（保存のたびに直前の版を `.bak` に残します） |
| `crm_settings.ini` | PCごとの設定（テーマ、一覧に表示する列） |
| `crm_log.txt` | コマンドライン実行のログ |

旧版（CrmDemo）の `crm_data.xml` をそのまま置くと、**対応履歴はケースへ自動移行**されます。

| 旧版の項目 | 移行先 |
|---|---|
| 対応日 | 通話日時 `call_date` |
| 問い合わせ内容 | 問い合わせ内容 `summary` |
| 対応内容 | 対応内容 `response` |
| 次回確認内容 | 次回確認内容 `next_action` |
| 担当者 | オペレータ `operator_name` |
| 次回確認日・状態 | 値がある場合だけ、同名のフィールドを自動で追加して引き継ぎます |

サンプルデータは `--sample`（GUI では［データ］→［サンプルデータを投入］）で投入できます。顧客8件・ケース18件で、通話ID・件名・通話日時・オペレータ・用件区分・通話詳細URL も入った状態になります。同じ内容は重複して入らないので、何度実行しても安全です。

```bash
build.bat
```

Windows 標準の C# コンパイラ（`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`）を使うので、Visual Studio や .NET SDK は不要です。成果物は `dist\CSDemoCRM2.exe`。

## 補足

- コマンドラインから標準出力を確実に受け取れるよう、コンソールアプリとしてビルドしています。ダブルクリックで起動したときは黒い画面が一瞬表示されてすぐ消えます。
- GUI を開いたままコマンドラインで起票しても、保存は競合しません（保存前に最新のデータを読み直します）。
- `--pick` の選択画面は、画面を表示できない環境（サービス実行など）では自動的に従来の動作に戻ります。無人の自動連携では `--pick` を付けないでください。
- 対象は Windows 限定です（Mac/Linux は非対応）。
